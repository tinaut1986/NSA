- Ao instalar a partir de uma URL ou de um QR, o NSA pergunta como: Instalar, Salvar e instalar, Salvar, instalar e excluir, ou Salvar; a tela superior explica cada opção.
- Links de compartilhamento do Google Drive funcionam: o NSA busca o arquivo sozinho, com o nome dele.
- Salvar um download grava em ordem, para o cartão SD acompanhar: velocidades constantes em arquivos grandes, tanto no New 3DS quanto no 2DS.
- Os downloads só abrem uma nova conexão quando ela é claramente mais rápida (no máximo quatro), e fecham uma se a velocidade despenca.
- Um link que leva a uma página web em vez de um arquivo avisa isso, em vez de salvar ou instalar a página.
