- System -> Konsoleneinstellungen -> WLAN-Verbindungen: Mit QR-Code einrichten füllt eine Verbindung mit dem Code, den ein Handy beim Teilen seines WLANs zeigt, oder dem eines Routers. Prüfen und speichern.
- QR-Code anzeigen bringt eine Verbindung oder eine gespeicherte Kopie auf den oberen Bildschirm, damit sich ein Handy verbinden kann.
- QR-Codes werden auch gelesen, wenn sie gespiegelt sind, wie der Code, den Android zum Teilen des WLANs zeigt.
- Eine lange Zeile auf einem Warte-Bildschirm (etwa der Hinweis des QR-Scanners) wird jetzt innerhalb ihrer Karte umbrochen.
- Das Kapitel WLAN-Verbindungen der Anleitung hat einen neuen Schritt zu QR-Codes.
