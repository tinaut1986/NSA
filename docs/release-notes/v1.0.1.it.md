- Le Impostazioni ora sono divise in gruppi, e Aspetto ha uno Sfondo animato dietro lo schermo superiore: bolle, neve, cielo stellato, lucciole, foresta incantata, fili di luce o energia. Con il cursore 3D alzato fluttua dietro lo schermo.
- La Musica di sottofondo riproduce anche le tue canzoni: metti file MP3, WAV, FLAC o Ogg in /nsa/music/ sulla scheda SD e scegline una, o Le mie canzoni per tutte.
- Server a console chiusa tiene attivi i server FTP e web con la console chiusa, e la Porta FTP si può scegliere: 5021, 5000 o 21.
- Installa da URL installa CIA e 3DSX e salva ogni altro file in /nsa/received/. Mentre riserva lo spazio per un file grande o ne elimina uno, avvisa di non spegnere la console.
- Impostare l'ora da internet non cambia più lo scarto orario delle Impostazioni della console, e un forwarder DS controlla prima nds-bootstrap e dice quale icona del menu HOME sostituisce.
