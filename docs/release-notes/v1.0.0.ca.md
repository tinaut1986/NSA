- NSA 1.0. El Menú principal ara és una graella: cada entrada gran o petita, on vulguis, també icones petites a dalt. S'edita amb SELECT o mantenint premuda una entrada.
- Instal·lació remota també es pot organitzar: mou o amaga les seves fitxes i els botons FTP i Web, i posa la barra d'Historial a sobre, entre o sota les fitxes.
- Targeta SD: les accions d'una carpeta tenen Calcula la mida, que mostra Què ocupa espai: el que hi ha a dins, de més gran a més petit, cadascun amb la seva part. Utilitats el té per a tota la targeta SD.
- Utilitats: el Firmware del DSP pot ser OpenDSP, un de codi obert (de GitHub, o la còpia que porta NSA), i Reassignació de botons canvia el que fan els botons a tots els jocs, o en un, amb Rehid.
- Títols mostra el cartutx que hi ha a la consola, i se'n pot fer còpia de la partida.
- La Guia té capítols per a tot això, i el logo d'arrencada mostra NSA sobre una targeta de cantonades arrodonides.
