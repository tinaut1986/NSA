- A .3dsx can be installed in the HOME Menu (SD card, the .3dsx's actions, "Install in the HOME Menu"): it becomes a real title, not a forwarder, so it starts and quits like any other and the .3dsx is no longer needed.
- Its icon and name come from the .3dsx; the banner is drawn from them, or made from a picture of yours.
- Installing the same .3dsx again updates the title; a newer .3dsx needs to be installed again to update it.
