- 商店：可通过二维码或链接添加你自己的商店（.unistore），查看商店提供的所有条目，打开后即可安装（不再等待检查主机上的应用）；zip 解压快得多。
- 文件：可选择多个项目，一次性复制、移动、安装或删除；大文件夹的删除更快。
- 游戏MOD：清理会列出 /luma/titles 中的 LayeredFS MOD 以及对应游戏是否已安装，删除游戏时也可选择同时删除其MOD。
- 音乐：按 B 后播放器会在后台继续播放，MP3 内可即时跳转，可列表循环或单曲循环。
- FTP：FileZilla 不再在每次传输前等待 20 秒；FTP 和网页传输会在主机上显示进度，网页地址会显示为二维码。
- 所有列表都可双向排序，筛选器改用图标，每个网格都有磁贴大小设置，Old 3DS 上的下载开始得更快。
