- 网页界面 PIN（设置 -> 网页 PIN）：每次启动都生成新的随机 PIN（与之前相同），或使用在数字键盘上输入或随机生成的固定 PIN，或不使用 PIN。当浏览器请求 PIN 时，主机会在屏幕底部显示它。
- 远程安装：历史记录旁的两个小按钮可开关 FTP 服务器和 Web 服务器，并显示它们的地址（Web 的还会显示 PIN 和二维码）。历史记录会显示最近文件的名称。
- 从 HOME 菜单启动时（已安装的 CIA）显示 NSA 自己的启动标志，有白天和夜间两种样式。
- 软件：“提取 ExeFS”会把软件的代码、图标、横幅和标志复制到 SD 卡。
- FTP：Dolphin 等会打开多个连接的文件管理器浏览时不再卡住（5 个会话，列表中只有一个文件，数据连接等待更久）。
- 指南：为以上内容新增了步骤，并修复了在其他行按 A 时 Wi-Fi 导览会卡住的问题。
