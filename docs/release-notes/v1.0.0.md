- NSA 1.0. The main menu is now a grid: each entry big or small, wherever you want it, small icons on top too. Edit it with SELECT or by holding an entry.
- Remote install can be laid out too: move or hide its tiles and the FTP and Web buttons, and put the History bar above, between or under the tiles.
- SD card: a folder's actions have Calculate size, which shows What takes the room: what is in it, biggest first, each with its share. Utilities has it for the whole SD card.
- Utilities: the DSP firmware can be OpenDSP, an open source one (from GitHub, or the copy NSA carries), and Button remapping changes what the buttons do in every game, or in one, with Rehid.
- Titles lists the game card in the console, and its save can be backed up.
- The guide has chapters for all of this, and the boot logo shows NSA on a card with rounded corners.
