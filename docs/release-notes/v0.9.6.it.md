- PIN dell'interfaccia web (Impostazioni -> PIN web): uno casuale nuovo a ogni avvio (come prima), uno fisso che digiti su un tastierino numerico o rendi casuale, oppure nessuno. Quando un browser chiede il PIN, la console lo mostra in fondo allo schermo.
- Installazione remota: due piccoli pulsanti accanto a Cronologia attivano o disattivano il server FTP e il server web, e ne mostrano l'indirizzo (quello web anche il PIN e un QR code). La Cronologia mostra il nome dell'ultimo file.
- Logo di avvio tutto di NSA quando parte dal menu HOME (il CIA installato), con un aspetto diurno e uno notturno.
- Titoli: "Estrai ExeFS" copia sulla scheda SD il codice, l'icona, il banner e il logo di un titolo.
- FTP: Dolphin e altri gestori di file che aprono più connessioni navigano senza bloccarsi (5 sessioni, un solo file in un elenco, attesa più lunga per le connessioni dati).
- Guida: nuovi passi per tutto questo, e il percorso del Wi-Fi non si blocca più se si preme A su un'altra riga.
