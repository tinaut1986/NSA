- Sistema -> Configurações do console -> Conexões Wi-Fi: Configurar por um código QR preenche uma conexão com o código que um celular mostra ao compartilhar o Wi-Fi, ou o de um roteador. Confira e salve.
- Mostrar código QR coloca uma conexão ou uma cópia salva na tela superior, para um celular se conectar.
- Os códigos QR também são lidos quando estão desenhados espelhados, como o que o Android mostra ao compartilhar o Wi-Fi.
- Uma linha longa numa tela de espera (como a dica do leitor de QR) agora quebra dentro do seu cartão.
- O capítulo Conexões Wi-Fi do guia tem um passo novo sobre códigos QR.
