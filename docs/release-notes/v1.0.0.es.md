- NSA 1.0. El Menú principal ahora es una cuadrícula: cada entrada grande o pequeña, donde quieras, también iconos pequeños arriba. Se edita con SELECT o manteniendo pulsada una entrada.
- Instalación remota también se puede organizar: mueve u oculta sus fichas y los botones FTP y Web, y pon la barra de Historial encima, entre o debajo de las fichas.
- Tarjeta SD: las acciones de una carpeta tienen Calcular tamaño, que muestra Qué ocupa espacio: lo que hay dentro, de mayor a menor, cada cosa con su parte. Utilidades lo tiene para toda la tarjeta SD.
- Utilidades: el Firmware del DSP puede ser OpenDSP, uno de código abierto (de GitHub, o la copia que trae NSA), y Reasignar botones cambia lo que hacen los botones en todos los juegos, o en uno, con Rehid.
- Títulos muestra el cartucho que hay en la consola, y se puede hacer copia de su partida.
- La Guía tiene capítulos para todo esto, y el logo de arranque muestra NSA sobre una tarjeta de esquinas redondeadas.
