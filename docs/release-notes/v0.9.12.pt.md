- O botão "Send to 3DS" de uma loja, como o "Send to 3dsDL" da Brewology, agora envia direto para o NSA: links para http://3ds.local/ (ou nsa.local) chegam ao console enquanto o NSA está aberto.
- Nada é baixado até você responder no console, e a pergunta diz de qual aparelho e de qual site vêm os links.
- De um celular ou computador no seu Wi-Fi, abra http://3ds.local/ para colar links; a página fica no idioma do console.
- Configurações -> Links de páginas da web desativa isso.
