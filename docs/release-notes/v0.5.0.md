- Saves: export, import and send the save data, extra data and SpotPass data of a title to another 3DS, with a list of every backup (NSA's and Checkpoint's) to restore, send or delete.
- A web page to manage the console from a computer's browser (Settings -> Web server, with a PIN): files, titles with icons, saves, installing from URLs, and the console's screens live with its buttons.
