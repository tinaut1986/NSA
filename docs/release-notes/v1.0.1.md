- Settings are in groups now, and Appearance has an Animated background behind the top screen: bubbles, snow, a starry sky, fireflies, an enchanted forest, threads of light or energy. With the 3D slider up it floats behind the screen.
- Background music plays your own songs too: put MP3, WAV, FLAC or Ogg files in /nsa/music/ on the SD card and pick one, or My songs for all of them.
- Servers with the lid closed keeps the FTP and web servers working with the lid shut, and the FTP port can be chosen: 5021, 5000 or 21.
- Install from URL installs CIAs and 3DSX and saves any other file in /nsa/received/. While it makes room for a big file or deletes one, it tells you not to turn the console off.
- Setting the clock from the internet no longer changes the time offset of System Settings, and a DS forwarder checks for nds-bootstrap first and says which HOME Menu icon it replaces.
