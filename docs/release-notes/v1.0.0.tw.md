- NSA 1.0。主選單現在是網格：每個項目可大可小，放在你想要的位置，也可以把小圖示放在上面。按 SELECT 或長按項目即可編輯。
- 遠端安裝也可以安排：移動或隱藏它的圖塊以及 FTP 和 Web 按鈕，並把記録列放在圖塊上方、中間或下方。
- SD：資料夾的動作裡有「計算大小」，會顯示「什麼佔用了空間」：裡面的內容從大到小排列，並顯示各自的佔比。工具裡可以對整張 SD 卡使用。
- 工具：DSP 韌體可以使用開源的 OpenDSP（從 GitHub 下載，或使用 NSA 內建的副本）；按鈕對應藉由 Rehid 改變所有遊戲或某個遊戲中按鈕的作用。
- 軟體清單會顯示主機中插著的遊戲片，並可以備份它的存檔。
- 指南為這些內容加入了章節，啟動畫面的標誌會顯示在圓角卡片上的 NSA。
