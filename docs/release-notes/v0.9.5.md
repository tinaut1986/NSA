- Taps near a list's right end press the row or button again: the scrollbar is grabbed only in the narrow gap beside it.
- The web page no longer hangs when a browser forces https:// on its port (HTTPS is not supported): that connection is closed at once so the browser falls back to http://, and a silent connection is dropped after 4 seconds instead of 30.
- FTP: when all 3 places are taken by connections left idle (a file manager such as Dolphin opens several), the one idle longest makes room for the new connection instead of answering "too many connections" until NSA restarts.
