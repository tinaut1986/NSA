- ダウンロードが高速化：大きなファイルはどのモデルでも8接続で受信し、catbox.moe などのサーバーでも分割され、止まった部分は再要求されます。インストール画面に接続数が表示されます。
- FTPとウェブページの転送が約2倍速くなり、FTPサーバーをオフにしてもNSAがフリーズしなくなりました。
- 「設定」 -> 「FTP中は音楽を停止」（Old 3DSでは初期設定でオン。停止しないほうが転送が10〜25%速くなります）。上部バーにFTPサーバーの動作中とウェブサーバーの起動中が表示されます。
- 「タイトル」の表示がずっと速くなりました。名前、アイコン、プロダクトコードは次回起動後も保持されます。
- 「システム」で詳細の一覧を開けます：本体、ネットワーク、SDカード、バッテリー。
- 別の画面を開く行には矢印が表示されます。
