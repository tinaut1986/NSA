- Dropboxのリンクからのダウンロードが、保存もインストールも動作します（以前は「Forbidden」で失敗していました）。
- URLからの大きなファイルの保存が高速化しました。長い単位で受信し、効果のある接続だけを開くので、その間もFTPとウェブページは応答し続けます。
- 転送は一度に1つだけ：2つ目の転送（FTP、ウェブページ、ダウンロード、別の3DS）にはすぐにその旨が伝えられ、両方が遅くなることはありません。ウェブページには転送中の内容が表示されます。
- FTPとダウンロードが少し速くなりました。
- フォルダごと別の3DSに送信でき、受信時に元のパスを保つか選べます。
- 削除の確認は赤で表示され、1つ上のフォルダに戻ると、元いたフォルダが選択されます。
