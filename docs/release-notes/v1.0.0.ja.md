- NSA 1.0。メインメニューがグリッドになりました。各項目を大きくも小さくも、好きな場所に置けます。小さなアイコンを上に置くこともできます。SELECTか項目の長押しで編集します。
- リモートインストールも並べ替えられます。タイルやFTP・Webボタンを動かしたり非表示にしたりでき、履歴のバーをタイルの上、間、下に置けます。
- SDカード：フォルダのアクションに「サイズを計算」があり、「容量を使っているもの」を表示します。中身を大きい順に、それぞれの割合つきで並べます。ユーティリティではSDカード全体で使えます。
- ユーティリティ：DSPファームウェアにオープンソースのOpenDSPを使えます（GitHubから、またはNSAに入っているコピー）。「ボタンの割り当て」ではRehidで、全部のゲームか一つのゲームのボタンの働きを変えられます。
- タイトルに本体に挿したゲームカードが表示され、そのセーブデータをバックアップできます。
- ガイドにこれらすべての章が加わり、起動ロゴは角の丸いカードの上にNSAを表示します。
