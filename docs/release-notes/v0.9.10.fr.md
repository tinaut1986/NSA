- Paramètres -> Nouveautés affiche les notes dans votre langue, une version par page : L / R tournent les pages, ZL / ZR vont à la première ou à la dernière, et l'écran du bas liste toutes les versions pour aller à l'une d'elles.
- Boutique : les 448 apps d'Universal-DB sont proposées, comme dans Universal-Updater. Celles qui écrivent dans boot.firm, /luma, /gm9 ou /private (Luma3DS, GodMode9, frameworks de plugins...) affichent d'abord un avertissement en rouge, de même que les téléchargements en http simple.
- Boutique : les autres options d'une app peuvent désormais retirer ce qu'elles ont installé (comme le "Remove the patch" d'un patch), et les entrées sans fichier indiquent qu'il n'y a rien à télécharger.
- Paramètres et les menus continuent de défiler après un glissement du doigt et ont les flèches rondes (et ZL / ZR sur une New 3DS) pour aller au début ou à la fin.
- Les rapports de bug et les idées sur GitHub commencent maintenant par un formulaire.
