- 一次向另一台 3DS 发送多个软件：在软件中选中它们（顶部的勾选图标），按 START。另一台主机只需回答一次即可全部接收，并根据可用空间为每个软件决定是边收边装还是作为安装包接收。
- 软件：选中软件后长按 A，可对它们一起操作：发送、导出为 CIA 或删除。
- 下载队列：来自商店或从 URL 安装的下载会在后台依次进行。可通过主菜单中的图标或网页暂停、继续或调整顺序。
- 商店：每个应用的图片，以及对商店安装的内容使用卸载 CIA / 删除 3DSX。
- 压缩包：查看内容可显示 zip 里有什么，从 URL 安装和远程安装会把它解压到 SD 卡上的正确位置（应用解压到 /3ds/<app>/）。
- 每个画面底部的按钮说明保持清晰可读，左侧的 (i) 可列出全部按钮。
