- Store: "Remove what the Store installed" takes away what an app's downloads put on the SD card (texture packs, mods, plugins...), wherever its steps put them. The Store notes every file it writes as it installs, so it removes exactly those.
- It asks first and says how many files and where. Files that replaced others that were already there are pointed out (deleting them doesn't bring the old ones back), files changed since are left, and the folders left empty go.
- It works for what is installed from this version on, and keeps no copies: nothing extra on the SD card.
