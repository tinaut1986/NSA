- 「ストア」：自分のストア（.unistore）をQRコードやリンクで追加でき、ストアが提供するすべての項目を表示し、開いてすぐにインストールできます（本体のアプリの確認を待たなくなりました）。zipの展開もずっと速くなりました。
- 「ファイル」：複数の項目を選んで、まとめてコピー、移動、インストール、削除ができます。大きなフォルダの削除も速くなりました。
- ゲームのMOD：「整理」が /luma/titles のLayeredFS MODと、そのゲームがインストール済みかを一覧にし、ゲームを削除するときにそのMODも削除するか尋ねます。
- 音楽：Bを押したあともプレーヤーがバックグラウンドで再生を続け、MP3内を即座にジャンプでき、リストまたは1曲のリピートに対応します。
- FTP：FileZillaが転送のたびに20秒待たなくなりました。FTPとウェブページの転送は本体に進行状況を表示し、ウェブページのアドレスはQRコードでも表示されます。
- すべてのリストを昇順・降順で並べ替えられ、フィルタはアイコンになり、すべてのグリッドでタイルの大きさを選べます。Old 3DSではダウンロードの開始も早くなりました。
