- «Магазин» следует шагам установки каждого приложения, как Universal-Updater: приложения в .zip или .7z теперь тоже устанавливаются и скачиваются (3D Pinball, 3DS Quick Reboot, mGBA и другие).
- Загрузка .3dsx из «Магазина» спрашивает только да или нет и сохраняет файл в /3ds/, без выбора вариантов для CIA.
- Заметка автора перед установкой читается как один абзац, без строк, оборванных посередине.
