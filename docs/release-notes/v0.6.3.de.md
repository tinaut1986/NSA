- Downloads über Dropbox-Links funktionieren, zum Speichern wie zum Installieren (sie scheiterten mit „Forbidden").
- Das Speichern einer großen Datei von einer URL ist schneller: Sie kommt in langen Stücken und öffnet nur die Verbindungen, die helfen, sodass FTP und Webseite währenddessen weiter antworten.
- Immer nur eine Übertragung: Eine zweite (FTP, Webseite, Download, andere 3DS) wird sofort abgewiesen, statt beide zu verlangsamen; die Webseite zeigt, was gerade übertragen wird.
- FTP und Downloads etwas schneller.
- Ganze Ordner an eine andere 3DS senden und beim Empfangen wählen, den ursprünglichen Pfad beizubehalten.
- Das Löschen fragt in Rot nach; beim Verlassen eines Ordners wird der, aus dem du kommst, ausgewählt.
