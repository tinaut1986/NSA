- NSA 1.0. «Главное меню» теперь сетка: каждый пункт большой или маленький, где угодно, маленькие значки сверху тоже. Меняется кнопкой SELECT или долгим нажатием на пункт.
- «Удаленную установку» тоже можно упорядочить: двигайте или скрывайте её плитки и кнопки FTP и Web, а панель «История» ставьте над плитками, между ними или под ними.
- «SD-карта»: в действиях папки есть «Посчитать размер», который показывает «Что занимает место»: содержимое от больших к меньшим, с долей каждого. В «Утилитах» это есть для всей SD-карты.
- «Утилиты»: «Прошивка DSP» может быть OpenDSP, открытой прошивкой (с GitHub или копией из NSA), а «Переназначение кнопок» меняет, что делают кнопки во всех играх или в одной, с помощью Rehid.
- «Приложения» показывают вставленный картридж, и его сохранение можно скопировать.
- В «Обучении» есть главы обо всём этом, а логотип при запуске показывает NSA на карточке со скруглёнными углами.
