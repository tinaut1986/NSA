- Быстрее загрузки: большие файлы приходят по 8 соединениям на любой модели, серверы вроде catbox.moe тоже делятся на части, а застрявший кусок запрашивается заново; экран установки показывает число соединений.
- Передача по FTP и через веб-страницу примерно вдвое быстрее, а выключение FTP-сервера больше не вешает NSA.
- «Настройки» -> «Пауза музыки при FTP» (по умолчанию включена на Old 3DS, где без паузы передача идет на 10-25% быстрее); верхняя панель показывает работу FTP-сервера и запущенный веб-сервер.
- Раздел «Приложения» открывается намного быстрее: названия, значки и коды продуктов сохраняются между запусками.
- «Система» открывает список сведений: консоль, сеть, SD-карта и батарея.
- Строки, открывающие другой экран, показывают стрелку.
