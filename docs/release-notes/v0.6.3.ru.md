- Загрузки по ссылкам Dropbox работают, и для сохранения, и для установки (раньше они завершались ошибкой «Forbidden»).
- Сохранение большого файла по ссылке стало быстрее: он приходит длинными кусками, открываются только полезные соединения, так что FTP и веб-страница продолжают отвечать.
- Одна передача за раз: вторая (FTP, веб-страница, загрузка, другая 3DS) сразу получает отказ вместо того, чтобы замедлять обе; веб-страница показывает, что передается.
- FTP и загрузки немного быстрее.
- Отправка целых папок на другую 3DS и возможность сохранять исходный путь при получении.
- Удаление спрашивает красным цветом; при выходе из папки выделяется та, из которой вы пришли.
