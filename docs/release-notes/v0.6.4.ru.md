- Сохранение по ссылке и отправка на другую 3DS используют только те соединения, которые ускоряют передачу, и находят их по ходу дела: часто быстрее, чем раньше, а консоль продолжает отвечать.
- Для отправки на другую 3DS эта версия нужна на обеих консолях.
- Копии сохранений показывают значки Checkpoint и NSA вместо надписей «[Checkpoint]» и «[NSA]».
