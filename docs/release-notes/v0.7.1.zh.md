- NSA 支持 11 种语言，可在设置的列表中选择：英语、西班牙语、加泰罗尼亚语、法语、德语、意大利语、葡萄牙语、俄语、日语和中文（简体和繁体）；“系统”选项跟随主机自身的语言。
- 从另一台 3DS 接收时会用列表询问（立即安装、保存、拒绝...），并说明每个选项的作用，上屏显示发送方和保存位置；也可发送整个文件夹。发送到另一台 3DS 需要两台主机都安装此版本。
- 从 URL 或二维码安装时会询问方式（安装、保存并安装、保存、安装并删除，或保存）；Dropbox 和 Google Drive 链接可用，链接和名称完整显示，%20 等会转换为字符，历史记录中也一样。
- 下载、FTP 和发送到另一台 3DS 更快，一次只进行一个传输且速度稳定。
- 网页新增系统标签页（主机、网络、存储、电池），可播放主机的音乐，把更新和 DLC 归到对应游戏下，并以提示条显示传输。
- 设置、远程安装和更新日志新增返回箭头；音乐不再因 FTP 而暂停，除非你要求（Old 3DS 会询问一次）。
