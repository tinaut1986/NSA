- 設定がグループ分けされ、外観にアニメーション背景が加わりました。上画面の後ろに泡、雪、星空、ホタル、魔法の森、光の糸、エネルギーを表示します。3Dボリュームを上げると画面の奥に浮かびます。
- BGMで自分の曲も流せます。MP3、WAV、FLAC、OggファイルをSDカードの/nsa/music/に入れて1曲選ぶか、自分の曲ですべてを流します。
- ふたを閉じてもサーバーを使うをオンにすると、ふたを閉じてもFTPとWebのサーバーが動き続けます。FTPポートは5021、5000、21から選べます。
- URLからインストールはCIAと3DSXをインストールし、それ以外のファイルは/nsa/received/に保存します。大きなファイルの領域を確保したり削除したりしている間は、電源を切らないよう表示します。
- インターネットからの時刻合わせで本体設定の時刻のずれが変わらなくなりました。DSのフォワーダーは先にnds-bootstrapを確認し、置き換えるHOMEメニューのアイコンを表示します。
