- Nouvelle Boutique : parcourez les homebrews d'Universal-DB avec icônes, recherche et filtres, installez le CIA ou téléchargez le 3DSX (aussi pour les applications fournies en .zip ou .7z, y compris sur Old 3DS et 2DS), et voyez ce qui est déjà sur la console.
- Un guide montre le fonctionnement de NSA avec de courtes visites sur les vrais écrans : vous faites chaque étape vous-même. Les versions suivantes ne proposent que les nouveautés (Paramètres -> Guide rejoue n'importe quel chapitre).
- Le menu principal est à vous : des tuiles et une rangée d'icônes que vous réorganisez en les faisant glisser ou que vous masquez, et le focus suit votre doigt.
- Le clavier à l'écran propre à NSA partout : recherches, noms et URL.
- Les longs messages défilent au-dessus de leurs boutons, une roue tournante s'affiche pendant un chargement, et toutes les nouveautés parlent les 11 langues.
