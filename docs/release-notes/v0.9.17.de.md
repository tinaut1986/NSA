- Hauptmenü -> Werkzeuge: wofür man früher Rosalina oder GodMode9 geöffnet hat. DSP-Firmware prüft /3ds/dspfirm.cdc (Ton für Homebrew) und liest sie aus, wenn sie fehlt; Spiel-Patching schaltet die Option von Luma3DS an oder aus; Neu starten und Ausschalten.
- SD-Karte -> eine .nds -> Im HOME-Menü installieren: ein Symbol, das das DS-Spiel mit nds-bootstrap startet. Die .nds bleibt auf der SD-Karte, und der Spielstand ist derselbe, den TWiLight Menu++ nutzt.
- Beim ersten Mal lädt NSA das Forwarder-Paket von nds-bootstrap herunter (etwa 2 MB), wenn es nicht auf der SD-Karte ist.
- Die Anleitung hat ein neues Kapitel, Werkzeuge, und das Kapitel SD-Karte einen Schritt zu DS-Spielen.
