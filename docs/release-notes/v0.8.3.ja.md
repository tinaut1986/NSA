- 新しい「ストア」：Universal-DBのホームブリューをアイコン、検索、フィルタつきで閲覧し、CIAのインストールや3DSXのダウンロードができます（.zipや.7zのアプリも、Old 3DSと2DSで可能）。すでに本体にあるものも確認できます。
- 「ガイド」が、実際の画面で短いツアーを通してNSAの使い方を示します。各ステップは自分で操作します。以降のバージョンでは新機能だけが案内されます（「設定」 -> 「ガイド」で任意の章をもう一度見られます）。
- メインメニューを自由に編集できます：タイルとアイコンの列をドラッグして並べ替えたり非表示にしたりでき、フォーカスは指に合わせて滑らかに動きます。
- NSA独自のスクリーンキーボードをどこでも使用：検索、名前、URL。
- 長いメッセージはボタンの上でスクロールし、読み込み中は回転するホイールが表示されます。新機能はすべて11言語に対応しています。
