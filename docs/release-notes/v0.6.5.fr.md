- L'installation depuis une URL ou un QR code demande comment faire : Installer, Enregistrer et installer, Enregistrer, installer et supprimer, ou Enregistrer ; l'écran du haut explique chacun.
- Les liens de partage Google Drive fonctionnent : NSA récupère le fichier lui-même, sous son propre nom.
- L'enregistrement d'un téléchargement s'écrit dans l'ordre, pour que la carte SD suive : des vitesses stables sur les gros fichiers, sur New 3DS comme sur 2DS.
- Les téléchargements n'ouvrent une nouvelle connexion que si elle est nettement plus rapide (quatre au maximum), et en ferment une si la vitesse s'effondre.
- Un lien qui mène à une page web plutôt qu'à un fichier le signale, au lieu d'enregistrer ou d'installer la page.
