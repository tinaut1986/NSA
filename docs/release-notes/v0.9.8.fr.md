- Un .3dsx peut être installé dans le menu HOME (carte SD, les actions du .3dsx, « Installer dans le menu HOME ») : il devient un vrai titre, et non un forwarder, donc il se lance et se quitte comme n'importe quel autre et le .3dsx n'est plus nécessaire.
- Son icône et son nom viennent du .3dsx ; la bannière est dessinée à partir d'eux, ou faite à partir d'une image de votre choix.
- Installer à nouveau le même .3dsx met le titre à jour ; un .3dsx plus récent doit être réinstallé pour mettre le titre à jour.
