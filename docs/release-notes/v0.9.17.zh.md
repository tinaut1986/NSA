- 主菜单 -> 工具：以前要打开 Rosalina 或 GodMode9 来做的事。“DSP 固件”检查 /3ds/dspfirm.cdc（自制软件的声音），缺少时会提取；“游戏补丁”开启或关闭 Luma3DS 的选项；还有“重启”和“关机”。

- 第一次使用时，如果 SD 卡上没有 nds-bootstrap 的 forwarder pack，NSA 会下载它（约 2 MB）。
