- I download dai link di Dropbox funzionano, sia per salvare sia per installare (prima fallivano con "Forbidden").
- Salvare un file grande da un URL è più veloce: arriva a pezzi lunghi, aprendo solo le connessioni utili, così FTP e pagina web continuano a rispondere nel frattempo.
- Un trasferimento alla volta: a un secondo (FTP, pagina web, download, un'altra 3DS) viene detto subito, invece di rallentare entrambi; la pagina web mostra cosa si sta trasferendo.
- FTP e download un po' più veloci.
- Invia cartelle intere a un'altra 3DS, e scegli di mantenere il percorso originale in ricezione.
- L'eliminazione chiede in rosso; salendo di una cartella si seleziona quella da cui si arriva.
