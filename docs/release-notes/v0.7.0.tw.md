- NSA 支援 11 種語言，可在設定的清單中選擇：英文、西班牙文、加泰隆尼亞文、法文、德文、義大利文、葡萄牙文、俄文、日文和中文（簡體和繁體）；「系統」選項跟隨主機本身的語言。
- 網頁新增系統分頁（主機、網路、儲存、電池），可播放主機的音樂，把更新和 DLC 歸到對應遊戲下，記住軟體的名稱和圖示，並以提示條顯示傳輸。
- 從 URL 或 QR 碼安裝時會詢問方式（安裝、儲存並安裝、儲存、安裝並刪除，或儲存）；Dropbox 和 Google Drive 連結可用。
- 下載、FTP 和傳送到另一台 3DS 更快，一次只進行一個傳輸且速度穩定；可傳送整個資料夾。傳送到另一台 3DS 需要兩台主機都安裝此版本。
- 設定、遠端安裝和更新內容新增返回箭頭；音樂不再因 FTP 而暫停，除非你要求（Old 3DS 會詢問一次）。
