NSA

An open source title manager for the Nintendo 3DS: install and manage titles, browse and view files, send games to another 3DS, and look after the console's own data. A fork of FBI with a new interface, new tools and its own updater.

Download the latest release Source on GitHub

BETA Latest beta

A fork of FBI that includes everything FBI does, so you do not need both. It installs as its own app (own title ID, data in sdmc:/nsa/) and never overwrites FBI. MIT license.

No piracy. NSA does not provide, host, link to or support pirated content, and the project will not help with it. NSA is a tool to manage software you legally own, your own backups and homebrew. Requests or links for pirated games will be removed.

Features

Install

  • CIAs and tickets from the SD card, from a computer on your network, or over the Internet with a URL or QR code
  • Remote install history to install again
  • Send a file or installed title to another 3DS running NSA (Wi-Fi or with no router); cut transfers resume
  • Export an installed title as a CIA

Store

  • Browse the homebrew of Universal-DB with icons, search, filters and sorting
  • Install an app's CIA or download its .3dsx
  • A mark shows what is already on the console

Titles, tickets and data

  • Titles as rows or an icon grid, with filters, search and sorting; updates and DLC grouped under their game
  • Launch, delete, extract icon, browse save data
  • Back up, restore and send save, extra and SpotPass data; finds Checkpoint backups
  • Tickets, Ext Save Data, Pending titles; DS cartridge saves
  • Optional web page to manage the console from your computer's browser, protected by a PIN

Files

  • Browse the SD card: copy, cut, rename, delete, new folder
  • Picture viewer (PNG, JPEG, BMP, GIF, TGA, 3D photos), text viewer/editor, audio player (MP3, WAV, FLAC, Ogg Vorbis)
  • Run a .3dsx from the list (needs Luma3DS)

Advanced

Behind a warning: browse and modify CTR NAND, TWL NAND, TWL photos and sounds, system save data, and dump the raw NAND to the SD. Only with NSA installed as a CIA, or run as a 3DSX under Luma3DS. A wrong change can stop the console from starting.

Look and feel

  • Customisable main menu; interactive guide
  • Three themes (Cards, Pixel, HOME), day/night colours, accent colours
  • 10 languages incl. English, Spanish, Catalan, French, German, Italian, Portuguese, Russian, Japanese, Chinese
  • Stereoscopic 3D, touch and buttons, optional sounds and generated background music
  • Self-updater with Stable and Beta channels

For developers

An FTP server (port 5021, on by default in Settings) serves the SD card. See the repository.

Install guide

You need: a Nintendo 3DS family console (Old or New 3DS/2DS) with custom firmware. As with FBI, NSA does not work on a console without custom firmware. Some tools need Luma3DS.

As a CIA (recommended)

  1. Download NSA-<version>.cia from the latest release.
  2. Copy it to your SD card.
  3. Install it with any CIA installer (FBI works, if you already have it) and launch NSA from the HOME menu. From then on NSA installs CIAs and updates itself, so you do not need FBI again.

As a 3DSX (Homebrew Launcher)

  1. Download NSA-<version>.3dsx and put it in /3ds/ on the SD card.
  2. Open it from the Homebrew Launcher.

Updating and channels

Once installed, NSA can update itself from Settings. Stable releases come from the master branch and are what "latest release" points to. Beta builds come from the release branch and are published as pre-releases on the releases page; a beta is promoted to stable once merged into master. Choose your channel in Settings.

FAQ

Do I still need FBI?

No. NSA is a fork of FBI 2.6.1 and keeps FBI's tools: installing CIAs and tickets from the SD card, from your network (servefiles-style), by URL or by QR code; titles, pending titles, tickets, ext save data and system save data; DS cartridge saves; browsing the SD card and NAND; and dumping the NAND. It is installed as a separate app, with its own title ID and its data in sdmc:/nsa/, so it does not overwrite FBI. You can keep both, but NSA alone is enough. You only need a CIA installer (FBI works) once, to install NSA the first time.

Does it work without custom firmware?

No, same as FBI.

Which consoles are supported?

The 3DS family. The README's screenshots come from a New 3DS XL and a 2DS; some newer features have so far run only in an emulator, so please report anything that fails on your model.

What is the difference between Stable and Beta?

Stable = master, the newest stable release. Beta = release, newer features that are not yet merged into master. A beta calls itself X.Y.Z-beta in the app.

Where does NSA keep its files?

In sdmc:/nsa/ on the SD card, including the transfer log transfer-log.txt.

Can you give me games?

No. NSA does not provide or support pirated content.

Is the web page / FTP safe?

The web page is off until you enable it and is protected by a PIN, but it is plain HTTP: use it only on your own network.

Report a problem

Found a bug or have an idea? Join the Discord or open a GitHub issue. Please include:

  • NSA version (Settings / System page, e.g. v0.8.4 or a beta)
  • Console model: Old or New 3DS / 2DS, and size (XL or not)
  • Firmware and CFW (e.g. 11.17 with Luma3DS)
  • Steps to reproduce, what you expected and what happened

Report a bug Suggest an idea Join the Discord

If an install fails, also check that the CIA is valid and try another SD card (counterfeit cards and filesystem errors are common causes). No pirated content in reports, please.
