- 主選單 -> 工具：以前要開啟 Rosalina 或 GodMode9 來做的事。「DSP 韌體」檢查 /3ds/dspfirm.cdc（自製軟體的聲音），缺少時會擷取；「遊戲修補」開啟或關閉 Luma3DS 的選項；還有「重新啟動」和「關機」。
- SD -> 一個 .nds -> 安裝到 HOME 選單：一個用 nds-bootstrap 啟動 DS 遊戲的圖示。.nds 留在 SD 卡上，存檔與 TWiLight Menu++ 使用的相同。
- 第一次使用時，如果 SD 卡上沒有 nds-bootstrap 的 forwarder pack，NSA 會下載它（約 2 MB）。
- 指南新增了「工具」章節，「SD」章節新增了一個關於 DS 遊戲的步驟。
