- Menu principal -> Utilitaires : ce pour quoi on ouvrait Rosalina ou GodMode9. Firmware du DSP vérifie /3ds/dspfirm.cdc (le son des homebrews) et l'extrait s'il manque ; Patch des jeux active ou désactive l'option de Luma3DS ; Redémarrer et Éteindre.
- Carte SD -> un .nds -> Installer dans le menu HOME : une icône qui lance le jeu DS avec nds-bootstrap. Le .nds reste sur la carte SD, et la sauvegarde est celle qu'utilise TWiLight Menu++.
- La première fois, NSA télécharge le forwarder pack de nds-bootstrap (environ 2 Mo) s'il n'est pas sur la carte SD.
- Le guide a un nouveau chapitre, Utilitaires, et le chapitre Carte SD une étape sur les jeux DS.
