- Wi-Fi接続：「システム」 -> 「ネットワーク」で、本体の3つの接続のコピーを（別名つきで）保管し、書き戻し、接続の編集と削除ができ、本体がオフラインのときはすぐに接続します。
- 「上級者向け」 -> 「NANDをダンプ」が、システムメモリをSDカードへより速くコピーし、最後のパーティションで止まります。
- すべての進行バーに残り時間が表示され、Bを押すとコピー、インストール、ダウンロードを止める前に確認されます（書きかけのものは削除されます）。
- FTPが中断した転送を再開できるようになり（REST）、FTPとウェブサーバーはWi-Fiを待ち、接続が戻ると一緒に復帰します。
- 「ストア」：Vapecordプラグイン、ndsForwarder、YANBFをインストールでき、CIAでも3DSXでもないアプリはインストール済みのときにその旨が表示されます。
