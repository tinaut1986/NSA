- Web interface PIN (Settings -> Web PIN): a new random one at each start (as before), a fixed one you type on a numeric keypad or make random, or none. When a browser asks for the PIN, the console shows it at the bottom of the screen.
- Remote install: two small buttons beside History turn the FTP server and the web server on or off, and show their address (the web one also its PIN and a QR code). History shows the last file's name.
- NSA's own boot logo when it starts from the HOME menu (the installed CIA), with a day and a night look.
- Titles: "Extract ExeFS" copies a title's code, icon, banner and logo to the SD card.
- FTP: Dolphin and other file managers that open several connections browse without hanging (5 sessions, a single file in a listing, a longer wait for data connections).
- Guide: new steps for all this, and the Wi-Fi tour no longer gets stuck when A is pressed on another row.
