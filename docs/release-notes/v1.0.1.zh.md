- 设置现在分组显示，外观中新增动态背景，显示在上屏后方：气泡、雪花、星空、萤火虫、魔法森林、光线或能量。打开3D时它会浮在屏幕后方。
- 背景音乐也能播放你自己的歌曲：把MP3、WAV、FLAC或Ogg文件放到SD卡的/nsa/music/中，选择一首，或选择我的歌曲播放全部。
- 合盖时保持服务器可让FTP和网页服务器在合盖时继续工作，FTP 端口也可以选择：5021、5000或21。
- 从 URL 安装会安装CIA和3DSX，其他文件保存到/nsa/received/。在为大文件预留空间或删除文件时，会提示不要关闭主机。
- 从网络设置时间不再改变主机设置中的时间偏移，DS转发器会先检查nds-bootstrap，并说明它会替换HOME菜单中的哪个图标。
