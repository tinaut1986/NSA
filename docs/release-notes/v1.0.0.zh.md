- NSA 1.0。主菜单现在是网格：每个项目可大可小，放在你想要的位置，也可以把小图标放在上面。按 SELECT 或长按项目即可编辑。
- 远程安装也可以布置：移动或隐藏它的图块以及 FTP 和 Web 按钮，并把历史记录栏放在图块上方、中间或下方。
- SD卡：文件夹的操作里有“计算大小”，会显示“什么占用了空间”：里面的内容从大到小排列，并显示各自的占比。工具里可以对整张 SD 卡使用。
- 工具：DSP 固件可以使用开源的 OpenDSP（从 GitHub 下载，或使用 NSA 自带的副本）；按键映射借助 Rehid 改变所有游戏或某个游戏中按键的作用。
- 软件列表会显示主机中插着的游戏卡，并可以备份它的存档。
- 指南为这些内容加入了章节，启动画面的标志会显示在圆角卡片上的 NSA。
