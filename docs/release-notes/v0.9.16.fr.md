- Système -> Paramètres de la console -> Connexions Wi-Fi : Configurer depuis un code QR remplit une connexion avec le code qu'affiche un téléphone quand il partage son Wi-Fi, ou celui d'un routeur. Vérifiez-la et enregistrez-la.
- Afficher le code QR met une connexion ou une copie enregistrée sur l'écran supérieur, pour qu'un téléphone s'y connecte.
- Les codes QR sont aussi lus quand ils sont dessinés en miroir, comme celui qu'affiche Android pour partager son Wi-Fi.
- Une longue ligne sur un écran d'attente (comme l'indication du lecteur de QR) passe maintenant à la ligne dans sa carte.
- Le chapitre Connexions Wi-Fi du guide a une nouvelle étape sur les codes QR.
